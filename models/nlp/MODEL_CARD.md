# SafetyOps Copilot NLP Model (DistilBERT)

## Overview

This directory is intended to hold the fine-tuned DistilBERT model used for
incident text classification in SafetyOps Copilot.

The model focuses on **incident severity classification** using short incident
descriptions (e.g. near-miss reports, safety logs). It is trained on a small
synthetic dataset generated by `scripts/download_text_dataset.py`.

- Base model: `distilbert-base-uncased`
- Task: single-label classification
- Target: `severity` ∈ {`low`, `medium`, `high`}

Category classification (e.g. `fall`, `electrical`, `fire`, `chemical`,
`ppe_noncompliance`, `other`) is currently implemented with a lightweight
rule-based classifier and is **not** learned by this model in v1.

## Training data

Run:

```bash
python scripts/download_text_dataset.py
```

This generates:

- `data/text/incidents_synthetic.csv`

The dataset includes columns:

- `text`: short incident description
- `category`: incident category (synthetic)
- `severity`: severity label (`low` / `medium` / `high`)

**Disclaimer:** the dataset is fully synthetic and intended only for
demonstration and testing. It does not represent real-world safety data and
must not be used for production risk assessment.

## Training

Training entry point:

```bash
python -m safetyops.ml.nlp.train
```

Key behavior:

- Loads `data/text/incidents_synthetic.csv` by default.
- Splits into train/validation subsets.
- Tokenizes text with `distilbert-base-uncased`.
- Fine-tunes using the Hugging Face `Trainer` API.
- Logs parameters, metrics and artifacts to **MLflow** using the tracking URI
  configured in `SAFETYOPS_MLFLOW_TRACKING_URI` (or application settings).
- Saves the best model under:

  - `models/nlp/` (this directory)

  including the tokenizer and config.

### Example metrics (illustrative only)

On the synthetic dataset, you can expect very high scores because the patterns
are simple and generated:

- Accuracy: ~0.95–1.0
- Macro F1: ~0.95–1.0
- Weighted F1: ~0.95–1.0

These metrics **do not** reflect performance on real data.

## Inference

The primary runtime entry point is:

- `safetyops.ml.nlp.infer.predict_severity(text: str)`

This function:

- Loads the fine-tuned DistilBERT model from `models/nlp/` (or the directory
  configured via `SAFETYOPS_NLP_MODEL_DIR`).
- Returns a `TextClassificationPrediction` object with:

  - `category`: derived from the rule-based classifier.
  - `severity`: predicted by DistilBERT (or rule-based fallback if the model
    is not available).
  - `confidence`: model probability for the predicted severity.

If the model directory is missing or cannot be loaded, the system falls back
to `safetyops.ml.nlp.classifier.classify_incident`, ensuring the worker and API
continue to operate in constrained environments and CI.

## Limitations

- Synthetic data only; no guarantee of real-world validity.
- Limited label space: `low`, `medium`, `high` severity only.
- No multilingual support in v1 (English-only synthetic texts).
- No explicit bias mitigation; dataset is artificial but still simplistic.

## Responsible use

This model is provided for **educational and prototyping purposes**. Any use
in real safety-critical environments must:

1. Replace the synthetic dataset with real, high-quality labeled data.
2. Undergo rigorous validation and calibration.
3. Be paired with clear human-in-the-loop processes.
